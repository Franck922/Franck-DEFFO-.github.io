# Portfolio · Franck DEFFO

Portfolio technique en cybersécurité, infrastructures et développement.
En ligne : **https://franck922.github.io/Franck-DEFFO-.github.io/**

Étudiant en Master Cybersécurité à l'EFREI Paris (M1 et M2, septembre 2026 à juillet 2028),
en recherche d'alternance sur un rythme d'une semaine d'école pour deux semaines en entreprise.

## Ce que contient le site

Treize projets menés en école et en autonomie, chacun avec sa page détaillée, son code
ou son rapport technique. Quatre domaines sont couverts.

| Domaine | Projets |
|---|---|
| Développement | SecureLink, plateforme Laravel et Vue.js, API REST Java Spring Boot, jeu 2D Unity |
| Sécurité opérationnelle | EDR et console SOC, SOC bancaire, modélisation MITRE ATT&CK et D3FEND |
| Infrastructures | POC Cyber Limited, Active Directory et VPN PKI, réseau multi-sites et IPsec, adressage VLSM et IPv6 |
| Gouvernance | Conformité HDS TeleCare, analyse de risques ISO 27005, pilotage agile et OWASP |

## Organisation du dépôt

```
index.html          page d'accueil du portfolio
_layouts/           gabarit Jekyll des pages projet
assets/style.css    feuille de style
Projets/            une page Markdown par projet
docs/               rapports techniques et livrables au format PDF
```

## Technologie

Site statique servi par GitHub Pages avec Jekyll. Aucune dépendance à installer :
toute modification poussée sur `main` est publiée automatiquement.
